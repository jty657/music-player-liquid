# Music Player Liquid

一款采用液态玻璃风格的Android本地音乐播放器,支持动态背景和流畅动画。

## ✨ 特性

- 🎨 **液态玻璃UI**: 采用玻璃拟态设计风格
- 🌈 **动态背景**: 根据专辑封面自动提取主色调
- 💿 **旋转封面**: 播放时专辑封面旋转动画
- 🎵 **音乐播放**: 基于ExoPlayer的音频播放
- 📱 **Material 3**: 采用最新Material Design 3设计规范

## 🛠 技术栈

- Kotlin
- Jetpack Compose
- Hilt (依赖注入)
- Media3 (ExoPlayer)
- Palette API (颜色提取)
- Coil (图片加载)

## 📦 构建

```bash
./gradlew assembleDebug
```
